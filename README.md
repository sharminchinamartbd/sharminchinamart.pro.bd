# Sharmin China Mart BD 🌿

A premium, mobile-first, and fully responsive e-commerce landing page built for **Sharmin China Mart BD**. This web application serves as a digital storefront for Chinese, Herbal, and Lifestyle products, allowing customers to browse items and place orders directly via WhatsApp and Facebook Messenger. 

It is built as a **Progressive Web App (PWA)**, meaning users can install it on their mobile devices like a native app and access core assets even offline.

## ✨ Features

- **📱 Mobile-First & Responsive:** Pixel-perfect layout across all devices (Desktop, Tablet, and Mobile).
- **🚀 Progressive Web App (PWA):** Includes `manifest.json` and `sw.js` for app installation and offline caching.
- **🛍️ Direct Ordering:** Seamless integration with WhatsApp and Facebook Messenger for instant customer communication.
- **💳 Modern UI/UX:** Features a clean design with Premium Glassmorphism effects (e.g., CTA section) and smooth CSS animations.
- **🔍 Custom Product Modals:** Detailed product views without leaving the main page.
- **🎠 Review Carousel:** An auto-scrolling customer review slider with touch/swipe support for mobile.
- **⚡ Fast & Lightweight:** Built entirely with Vanilla web technologies without heavy frameworks.

## 🛠️ Technologies Used

- **HTML5:** Semantic markup and structuring.
- **CSS3:** Custom properties (variables), CSS Grid, Flexbox, Glassmorphism, and responsive media queries.
- **Vanilla JavaScript:** DOM manipulation, modal handling, slider logic, and PWA install prompts.
- **Service Worker:** For caching core files (`index.html`, `style.css`, etc.) to provide an offline fallback.
- **Font Awesome:** For scalable vector icons.
- **Google Fonts:** Utilizing 'Hind Siliguri' (Bengali) and 'Poppins' (English).
